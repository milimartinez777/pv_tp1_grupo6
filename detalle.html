Sistema de Gestión de Biblioteca Escolar

Fecha de Inicio: 08 DE MARZO 2026

Autores: Rosalind Franklin, Christina Koch

DESCRIPCION:

Esta aplicación web tiene como objetivo mejorar la gestión de una biblioteca escolar mediante el registro organizado de préstamos, devoluciones y disponibilidad de libros. A través de una interfaz sencilla, los usuarios pueden consultar el catálogo, verificar qué libros están disponibles y realizar solicitudes de préstamo de manera más eficiente. Esto permite optimizar el uso de los recursos bibliográficos y facilitar el acceso a la información para estudiantes y docentes.

Además, el sistema contribuye a un mejor control administrativo, ya que permite llevar un seguimiento detallado de los libros prestados y las fechas de devolución, reduciendo pérdidas y retrasos. De esta manera, se promueve el uso responsable del material educativo y se moderniza el funcionamiento de la biblioteca, integrando herramientas digitales que mejoran la organización y el servicio ofrecido a la comunidad educativa.
